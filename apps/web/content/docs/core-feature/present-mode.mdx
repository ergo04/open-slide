## Fullscreen playback

From the dev server, hit **Present** (or press `f`). The current deck goes
fullscreen, scaled uniformly to fit the screen:

- Arrow / space / `PgDn` to advance.
- `←` / `↑` / `PgUp` to go back.
- `Home` / `End` to jump to first / last.
- `Esc` to exit.

## Presenter view

Press `p` (or the presenter button in the present control bar) to open the
presenter view in a second window:

- **Current slide** at the size you'll show it.
- **Next slide** preview.
- **Speaker notes** for the current page.
- **Timer** — elapsed time since you entered present mode.

Keep it on the laptop screen while the deck mirrors to the projector.

## Speaker notes

Add notes alongside the page array — an array of strings, index-aligned with
the pages (use `undefined` to skip a page):

```tsx
export const notes = [
  'Open with a smile. Mention the analyst quote from yesterday.',
  undefined,
  'Pause here for questions. The chart is a hand-off.',
];
```

## Custom presenter transport

The projection and presenter windows talk over a `BroadcastChannel`, which
only reaches windows of the same browser. To drive the deck from another
device — a phone as a remote, a second laptop — replace the transport from a
Vite plugin (added through [`vite.plugins`](/docs/reference/config#vite)) by
resolving `virtual:open-slide/presenter-transport` to your own module:

```ts title="remote-transport.ts"
import type { CreatePresenterTransport } from '@open-slide/core';
import { createBroadcastTransport } from 'virtual:open-slide/presenter-transport/broadcast';

export const createPresenterTransport: CreatePresenterTransport = (options) => {
  const local = createBroadcastTransport(options);
  // Open your network link here and forward messages to options.onMessage.
  return {
    send(msg) {
      local?.send(msg);
      // …and send msg over the network.
    },
    close() {
      local?.close();
    },
  };
};
```

```ts title="open-slide.config.ts"
import path from 'node:path';
import type { OpenSlideConfig } from '@open-slide/core';

const transport = path.resolve('remote-transport.ts');

const config: OpenSlideConfig = {
  vite: {
    plugins: [
      {
        name: 'remote-transport',
        resolveId: (id) => (id === 'virtual:open-slide/presenter-transport' ? transport : null),
      },
    ],
  },
};

export default config;
```

The projection window answers `request-state` with a `state` message and
re-publishes `state` on every change, so a presenter view that joins late
only needs to send `request-state` once its link is open.
